## book-store

The storefront with routing, a parameterized child route, and a guarded admin
page. 

```bash
cd book-store
npm install
ng serve                # http://localhost:4200
ng test --watch=false   # 21 tests
ng build
```

Log in as `admin` / `password` to reach the Admin page.
